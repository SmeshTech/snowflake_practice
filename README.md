# snowflake_practice# Snowflake Practice

A repository documenting hands-on practice and implementation of core Snowflake database management concepts.

## 🛠️ Snowflake Skills Demonstrated

### 1. Database & Schema Management
- **DDL Execution**: Creating and configuring databases (`CREATE DATABASE`)[cite: 2].
- **Table Design**: Defining structured tables within schemas using explicit data types (`VARCHAR`, `INT`)[cite: 2].

### 2. Data Ingestion & Manipulation (DML)
- **Data Insertion**: Writing multi-row `INSERT INTO` queries to populate tables with structured record sets[cite: 2].
- **Data Querying**: Fetching and analyzing dataset records using standard SQL selection queries (`SELECT`)[cite: 2].

### 3. Snowflake Environment Navigation (Snowsight UI)
- **Worksheets & Workspaces**: Managing and executing modular SQL files (`Practice.sql`, `Trial1.sql`, `Monday.sql`, `Simethembe.sql`)[cite: 1].
- **Role & Compute Management**: Working within specific administrative contexts (`ACCOUNTADMIN`) and warehouse sizing (`COMPUTE_WH` X-Small)[cite: 1].
- **Database Context**: Explicitly setting active databases and schemas (`SUNWARD.PUBLIC`) for query execution[cite: 1, 2].
